# 연습 과제 (WinForms, .NET Framework 4.8)

솔루션: `Practice.sln` (VS 2022 17.14에서 열기). 프로젝트 3개는 모두 빈 폼만 있다.
SDK 방식 csproj라서 새 `.cs` 파일을 만들면 자동으로 포함된다(`<Compile Include>` 불필요).

## 규칙
1. 기존 코드(copyApp, sendProject)는 **읽기 → 보고 치기 → 덮고 치기** 순서로만 본다. 복사 금지.
2. LINQ 체이닝 금지, 명시적 `for`/`foreach`.
3. 막히면 `STUCK.md`에 한 줄 적는다. 20분 막히기 전에는 정답을 보지 않는다.
4. 컨트롤은 Designer 없이 코드로 만든다.

## 상대 프로그램 (직접 만들기 전에 테스트용으로 사용)
| 용도 | 방법 |
|---|---|
| 시리얼 상대 | com0com 가상 포트 COM8↔COM9. 연습 앱은 COM9, 상대는 COM8 |
| 장비/MES 에뮬레이터 | `sendProject\sendProject\bin\Debug\sendProject.exe` 실행 → 포트 COM8 연결, TCP 서버 시작(127.0.0.1:8000) |
| 아직 상대가 없는 과제 | P1 연습 앱 2개를 나눠 실행(서버/클라이언트) |

sendProject 에뮬레이터 응답: 요청에 `CHECK`가 있으면 `01CHECK,OK`, `TEMP`가 있으면 `01TEMP,OK,t1,t2,t3,t4`,
`바코드,:SWITCH:ON?` / `:SWITCH2:ON?` / `:SWITCH2:OFF` 에 반응하고 완료 시 `01DONE,OK,<단계>`를 보낸다.
프레임: 시리얼 `STX(0x02)+본문+CR LF`, TCP `STX+본문+ETX`, TCP 본문 구분자는 `/` (T1/T2/T3).

## P1_Comm — 11/9 ~ 11/12 (뼈대와 통신)
11/8은 개념 리뷰만 한다 (`PLAN.md` 4절). 전체 일정과 체크박스는 `PLAN.md` 참고.

| 날 | 과제 | 합격 기준 |
|---|---|---|
| 11/9 | **UI 스레드 + 이벤트 + 타이머**: 백그라운드 `Thread`가 1초마다 카운터를 올려 라벨에 표시, 이벤트 발행/구독, `System.Timers.Timer` 5초 워치독 | ① 직접 대입 시 예외를 확인 ② `InvokeRequired`/`BeginInvoke`로 해결 ③ `Invoke`로 교착을 일부러 만들고 이유를 설명 ④ 세 가지를 각 10분 안에 작성 |
| 11/10 | **시리얼 파서**: `SerialPort` 열기, `DataReceived`, 버퍼 누적, `STX…CRLF` 분리 | 프레임이 2조각으로 와도, 2개가 붙어 와도 정상. 연결/해제 반복해도 멈추지 않음 (`WriteTimeout` 설정) |
| 11/11 | **TCP**: `TcpListener` 서버(포트 8001, 8000은 sendProject 사용) + `TcpClient`, `STX…ETX` 파서 | 접속/종료 감지, 쪼개짐/붙음 처리 |
| 11/12 | **저장(오전) + 점검 1(오후)**: 설정과 레시피 JSON 저장/불러오기, 로그 파일 → 미니 시리얼 터미널 (5시간, 참고 금지) | 재시작해도 값 복원, 파일 없거나 깨져도 기본값으로 시작. 터미널은 포트 선택, 연결/해제, 송신, 수신 로그, 설정 저장 |

## P2_Hmi — 11/13 ~ 11/17 (HMI)

| 날 | 과제 | 합격 기준 |
|---|---|---|
| 11/13 | View/Model 분리: `MainForm`(화면)과 `Model`(통신, 상태)을 이벤트로 연결 | Model은 `System.Windows.Forms`를 참조하지 않음 |
| 11/14 | 하트비트와 폴링: `CHECK` 5초 주기, 3회 무응답 시 연결 끊김 처리, 온도 폴링, PV 4개 표시 | 에뮬레이터의 "응답 중지"를 켜면 끊김 표시, 끄면 복구 |
| 11/15 | 사이클 상태머신: 바코드 확정 → `:SWITCH:ON?` → 1차 완료와 MES 완료 대기 → `:SWITCH2:ON?` → 완료. 중복 전송 방지, 실패 시 `:SWITCH2:OFF` | 온도 수신으로 `:SWITCH:ON?`가 다시 나가지 않음. 완료 보고를 끄면 제한시간 후 중단하고 다음 사이클 가능 |
| 11/16 | MES 클라이언트: `T1→T2→T3` 상태머신 + 5초 워치독 + NG 처리 | 정상 시 3단계 완료, NG나 타임아웃 시 Idle로 복귀하고 화면에 사유 표시 |
| 11/17 | **점검 2**: 미니 HMI (연결 → 사이클 → 장애) | 시리얼 끊김, TCP 끊김에도 UI가 멈추지 않음 |
