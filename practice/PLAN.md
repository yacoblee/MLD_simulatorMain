- 하루 8시간 이상. 12/1부터 본 업무 시작.
- 11/8은 개념 리뷰만 하고, **직접 개발은 11/9부터** 시작한다.
- 연습 솔루션: `practice\Practice.sln` (P1_Comm, P2_Hmi, P3_Mes). 과제 세부와 합격 기준은 `DRILLS.md`, 막힘 기록은 `STUCK.md`.
- 규칙: 복사 금지(읽기 → 보고 치기 → 덮고 치기), LINQ 체이닝 금지, Designer 없이 코드로 UI 작성.

## 2. 졸업 기준 (11/28)
미니 HMI + 미니 MES를 **참고 없이 처음부터** 작성하고 아래를 통과한다.
1. 정상 사이클: 바코드 확정 → 장비 1차 → MES T1~T3 → 장비 2차 → 완료
2. 시리얼 끊김(또는 응답 중지)에도 UI가 멈추지 않고 사이클이 중단·복구된다.
3. TCP 끊김 / MES NG / 타임아웃에서 상태가 Idle로 돌아오고 다음 사이클이 가능하다.

API 세부 이름은 검색해도 된다. 구조(클래스 분리, 이벤트 연결, 상태 전이)는 머릿속에서 나와야 한다.
